# strava_connection

Export and analysis of Strava activities.

- `data/activities.csv` – 100 activities (2026-06-13 → 2026-11-15) pulled via the Strava MCP connector
- `analyze.py` – sport breakdown, weekly volume, road-run pace trend; writes `output/`

```bash
pip install pandas matplotlib tabulate
python3 analyze.py [data/activities.csv] [output]
```

## Vercel

`index.html` is a static dashboard generated by `python3 build_site.py`; Vercel serves it from the repo root with no build step.

`data/summits.json` holds summit and high-point coordinates identified from Strava GPS tracks; `build_site.py` turns it into the Summits table in `index.html` and the Leaflet map in `map.html`.
